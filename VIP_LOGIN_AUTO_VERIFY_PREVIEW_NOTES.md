# VIP Login Auto-Verify Preview

This preview changes the launch flow:
- The VIP gate is shown on every fresh app launch.
- A previously saved demo key is checked after a 3-second verification screen.
- A valid saved demo key continues into 3106 without asking the user to type it again.
- First-time activation saves the demo key locally.

Demo key: `VIP-DEMO-2026`

IMPORTANT: This is only a local UI/flow preview. The demo key is embedded in the app and can be extracted or bypassed. It is NOT production license security. Real expiry, one-device binding, ban/unban, reseller controls, maintenance control, and automatic online verification require a server API and a secure backend. No Telegram bot token or secret should be placed in this app or public repository.
